# Mechanisms of Prospective Memory Performance: Exploring Depression-Related Impairments in Metamemory, Cue Detection, And Intention Retrieval

This dissertation examined the role of depression, metamemory, and neural activity in predicting prospective memory performance.
I ran regression, mediation, interaction, moderated mediation, and SEM models in R (lavaan, psych, tidyverse, mediate). 
Variables of interested included: 
  - depression: CES-D, PHQ-9
  - metamemory: JOLs, cognitive confidence ratings, PRMQ
  - neural activity: N300 and prospective positivity ERP components
  - behavior: prospective memory accuracy and reaction time
